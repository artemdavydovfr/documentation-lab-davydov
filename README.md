# StudentChat (Чат-додаток для студентів)

## Опис системи та проблема
**StudentChat** — це спеціалізований вебдодаток для обміну повідомленнями та оперативної комунікації між студентами та викладачами. Сучасні студенти часто стикаються з проблемою розпорошеності навчальних матеріалів та важливих оголошень по різних месенджерах, що призводить до втрати важливої інформації. Наш продукт вирішує цю проблему, об'єднуючи групові чати за предметами, обмін файлами та сповіщення в єдиній зручній платформі.

## Основні функції
* Створення та приєднання до групових чатів за навчальними дисциплінами.
* Обмін текстовими повідомленнями та навчальними матеріалами (файлами).
* Система сповіщень про важливі оголошення від старости або викладачів.
* Пошук по історії повідомлень та файловому архіву.

## Для кого цей продукт
Продукт розроблений для студентів коледжів та університетів, викладачів, старост груп, а також кураторів навчальних проєктів.
