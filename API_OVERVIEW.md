# Огляд API (API Overview)

Цей документ описує основні програмні інтерфейси (API) для взаємодії з системою студентського чату.

## 1. Отримання списку каналів (GET)
Отримує перелік доступних навчальних каналів та чатів для користувача.

* **URL:** `/api/v1/channels`
* **Метод:** `GET`
* **Приклад відповіді (JSON):**
```json
{
  "status": "success",
  "data": [
    { "id": 1, "name": "Кібербезпека-41", "type": "group" },
    { "id": 2, "name": "Програмна інженерія", "type": "group" }
  ]
}
2. Відправка повідомлення (POST)
Додає нове текстове повідомлення у вибраний канал чату.

URL: /api/v1/messages

Метод: POST

Приклад запиту (JSON):

JSON
{
  "channel_id": 1,
  "user": "Артем Давидов",
  "text": "Привіт, чи є у когось матеріали до лабораторної?"
}
Приклад відповіді (JSON):

JSON
{
  "status": "sent",
  "message_id": 105,
  "timestamp": "2026-10-26T12:00:00Z"
}
3. Коди помилок (Error Codes)
200 OK — Запит виконано успішно.

201 Created — Повідомлення або ресурс успішно створено.

400 Bad Request — Невірний формат даних у запиті.

401 Unauthorized — Помилка автентифікації (необхідно увійти в систему).

404 Not Found — Запитаний канал або ресурс не знайдено.

500 Internal Server Error — Внутрішня помилка сервера.
