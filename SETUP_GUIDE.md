# Довідник з інсталяції та запуску

## Необхідні інструменти
Для роботи з макетом та запуску проєкту потрібні такі інструменти:
* Сучасний веббраузер (Google Chrome, Firefox або Microsoft Edge останньої версії).
* Підключення до мережі Інтернет.
* Створений акаунт студентської пошти для авторизації в системі.

## Кроки встановлення та запуску (макет)
1. Перейдіть до головної сторінки репозиторію та завантажте проєкт або клонуйте його через термінал:
   ```bash
   git clone [https://github.com/artemdavydovfr/documentation-lab-davydov.git](https://github.com/artemdavydovfr/documentation-lab-davydov.git)

Перевірка роботи
Як зрозуміти, що все запущено правильно:

Сторінка завантажується у браузері без помилок, інтерфейс чату відображається коректно.

У консолі розробника (натисніть F12) відсутні критичні помилки JavaScript.

Кнопки навігації, перемикання каналів та поле введення повідомлень реагують на кліки та працюють згідно з макетом.
